## ✨ Overview

**Portioned** is an automated savings and budgeting app that helps users grow their savings without thinking about it. By splitting income, rounding up spending, and automating transfers into savings goals, it turns good financial habits into something that just happens in the background.

---

## 💼 Why Users (and Clients) Love This

- 🤖 **Automated Savings** — Round-ups, recurring transfers, and rule-based saving that happens without manual effort
- 🎯 **Goal-Based Savings Jars** — Users create separate savings goals and track progress toward each one
- 📊 **Smart Budgeting** — Income is automatically portioned across spending, bills, and savings categories
- 🏦 **Secure Bank Connections** — Linked accounts sync balances and transactions safely and in real time
- 📈 **Spending Insights** — Clear breakdowns of where money goes each week and month
- 🔔 **Savings Milestones & Alerts** — Notifications that celebrate progress and keep users motivated
- 🔐 **Bank-Grade Security** — Encrypted data and secure authentication protecting every account
- 🖥️ **Admin Dashboard** — Full visibility into users, accounts, and system activity for the operations team
- 📱 **Smooth Mobile Experience** — A fast, native-feeling app that makes saving feel effortless
- 🔁 **Reliable, Always-On Sync** — Balances and transactions stay accurate and up to date at all times

| Layer | Description |

---

## 🛠️ Tech Stack (Under the Hood)

**Mobile App:** Flutter & Dart (single codebase for iOS & Android)
**Admin Dashboard:** Next.js — internal tool for user & account management
**Backend:** Node.js, TypeScript, Prisma ORM, PostgreSQL — powering savings automation and transaction logic
**Cloud & Infrastructure:** AWS (RDS), Docker, Nginx
**Deployment:** Automated CI/CD pipelines with containerized, reproducible deployments

This stack keeps savings automation **accurate, secure, and reliable**, running consistently in the background for every user.
